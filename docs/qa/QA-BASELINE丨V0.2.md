## 2. 基线包含的功能范围（应全部可用）

- M1 记录：拍照/相册、语音转文字、AI 整理确认（AiConfirm）
- M2 画廊：卡片流、地点详情（PlaceDetail）、记录详情（EntryDetail，**含新编辑功能**）
- M3 记录流：地点聚合页、时间轴
- M4 回顾：地图、标签统计
- M5 找地点：自然语言搜索
- M6 分享：单地点/清单快照（本地）、分享页渲染
- 云同步：登录、outbox 队列、云朵状态、revision 乐观锁、冲突登记（单设备内只验证状态流转，不模拟并发）

## 3. 本轮新增功能（重点测试）

**「编辑已有记录」**（EntryDetail）：详情页操作行 = 分享 / 编辑 / 删除。编辑表单可改评分、到访日期、人均、感受（私密）、公开推荐理由、标签；保存 → revision+1 → 云同步。

## 5. 回归 Checklist（逐项执行，每项留截图/网络证据）

### A. 编辑功能（新增，6 项）
- [ ] A1 详情页出现「编辑」按钮，点击进入表单，字段回填正确（评分/日期/人均/感受/理由/标签与原值一致）
- [ ] A2 改评分+文字 → 保存 → 详情页立即反映新值；云朵「已同步」
- [ ] A3 同步后刷新页面 → 新值保留（云端持久化）
- [ ] A4 标签编辑：加一个标签+删一个标签 → 保存/同步/刷新 → 与所选一致（不复活、不丢失）
- [ ] A5 编辑中点「取消」→ 不产生任何写入（outbox 无新条目、数据不变）
- [ ] A6 Network 核对：保存时 PATCH/POST 到 `rest/v1/entries`，回执 revision 较改前 +1

### B. 标签同步回归（T1–T8，含 K2 两个未实测修复）
- [ ] T1 登录态正常，云朵可到「已同步」
- [ ] T2 「验收测试地点」重打 2~3 个标签 → 同步 → 刷新 → 保留
- [ ] T3 新建「验收标签测试A」：1 演示标签 + 1 新建标签 → 同步 → 刷新 → 都在
- [ ] T4 删 1 个标签 → 同步 → 刷新 → 该标签消失、其余保留
- [ ] T5 Network：`tags`/`entry_tags` 推送 200/201；GET `entry_tags` 与页面一致
- [ ] T6 改评分/文字 → 同步 → 刷新保留，revision 递增
- [ ] T7 **带父链标签**（子标签如「└拿铁」其父「咖啡」从未单独打过）→ 打上子标签 → 同步 → 刷新 → 子标签保留且父标签自动上云（验证 K2 修复①）
- [ ] T8 连续快速打/删多个标签后立即同步 → 无卡死、无「云端标签保存失败」气泡、刷新后状态与页面一致（验证 K2 修复② outbox 不卡批）

## 6. 通过标准与报告

- **每项 = 通过/失败/阻断 + 证据**（截图路径、请求 URL、状态码、revision）
- 任一 A/B/D 项失败 → 整轮 FAIL
- 报告写入 `docs/qa/QA-REPORT丨V0.2.md`，结论：`QA_V02_PASS` / `QA_V02_FAIL` + 失败清单

## 7. 禁止事项（QA 红线）

1. 不修改任何代码、不执行 SQL、不用 service_role/secret key、不动 Supabase Dashboard
2. 不删已有「验收」数据；新测试数据一律带「验收」字样
3. 不测双设备/并发（产品定位单设备）
4. Google 登录如遇自动化拦截：直接真实 Chrome + CDP（独立 profile 指 /tmp），判定 = `navigator.webdriver === false` 且 UA 无 Headless/Chrome for Testing
