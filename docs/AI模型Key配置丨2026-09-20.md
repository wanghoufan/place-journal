# AI 模型 Key 配置（2026-09-20）

> Key 只放服务端，绝不进前端页面、Git、截图。PWA 设置页只存模型名。

## 一、Key 获取链接（已核验对口页面）

- DeepSeek：https://platform.deepseek.com/api_keys （登录 → API Keys → 新建）
- OpenCode Go：先登录 https://opencode.ai 进 Zen 订阅 Go 后复制 Key；模型与端点说明：https://opencode.ai/docs/go
- OpenRouter（可选）：https://openrouter.ai/keys

## 二、Vercel 后台填变量（生产）

Vercel 项目 → Settings → Environment Variables，逐个加：

| 变量 | 填什么 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | （粘你的 Key） | 必填其一 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 现行默认；旧 `deepseek-chat` 2026-07-24 已退役 |
| `OPENCODE_API_KEY` | （粘你的 Key） | go 套餐 |
| `OPENCODE_BASE_URL` | `https://opencode.ai/zen/go/v1` | 填 base，会自动补 `/chat/completions` |
| `OPENCODE_MODEL` | （你的套餐模型名） | 不知道就空着，PWA 设置页自填也行 |
| `OPENROUTER_API_KEY` | （可选） | 有就填 |
| `AI_PROVIDER_ORDER` | `deepseek,opencode,openrouter` | 按你的优先顺序排，哪个有 Key 先走哪个 |

填完 Redeploy 一次生效。

## 三、本地联调（本机）

根目录复制 `.env.example` 为 `.env.local`，把上面同样的变量填进去，重启 `npm run dev`。

## 四、PWA 设置页用法

页面 `/ai-settings`（我的 → 隐私与 AI → 模型名设置）：三家各有下拉（现行名）＋自填框。
以后官方改名，你自己在框里填新名就行，不用改代码。填完点“测试全部通道”，显示可用·模型·耗时即通。

## 五、手机端

`mobile/.env` 加一行 `EXPO_PUBLIC_AI_API_BASE=https://你的域名`（留空＝本地占位，不联网）。
改了 `EXPO_PUBLIC_*` 要重建 dev 包才生效。
