`adb shell pm query-activities -a android.intent.action.VIEW -d
"com.wanghoufan.placejournal://auth/callback"` 返回空（全机无人注册该 scheme），
而 exp:// 命中 host.exp.exponent.LauncherActivity。代码把 redirectTo 硬编码为基线值
（mobile/src/supabase/redirect.ts:43），Custom Tab 认证完跳该 scheme 没人接，
openAuthSessionAsync 永远等不到 success。
定论：Expo Go 做不了自定义 scheme 的回跳，这是计划里写死的边界；T062 硬前置=Development Build。
严禁为了在 Expo Go 里跑通而临时改 redirect 到 exp://（PLAN 禁临时 scheme，还要改 Supabase allow list）。
